Sistema Anti-Sleep 24/7 para Render

Mecanismo Activo Anti-Inactividad

En el plan gratuito de Render, las aplicaciones entran en modo de suspensión (Sleep) tras 15 minutos sin peticiones entrantes. Este módulo ejecuta un auto-ping cada 10 minutos hacia sí misma para mantenerse activa permanentemente.

Configuración de Keep-Alive

En Render se detecta automáticamente a través de la variable RENDER_EXTERNAL_URL.

Estado del Auto-Ping: Activo
Total Pings Enviados: 0
Último Ping: Ninguno
Tiempo Activo (Uptime): 0 min

Pasos para Subir a Render y Asegurar 24/7

1 Subir Código a GitHub

Crea un repositorio en GitHub con esta carpeta y haz un git push.

2 Crear Web Service en Render

En render.com selecciona New Web Service, conecta tu repositorio. Build command: npm install, Start: npm start.

3 Auto-Detección Keep-Alive

Render inyecta automáticamente RENDER_EXTERNAL_URL. El servidor se auto-pingea cada 10 min de forma transparente.

4 Respaldo UptimeRobot (Opcional)

Para garantía del 100%, agrega en UptimeRobot.com un monitor HTTP a /api/health cada 5 minutos gratis.
